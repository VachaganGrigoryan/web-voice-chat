# Screenshots

Every PNG in this folder is generated by `npm run docs:screenshots`. Do not edit or replace them by hand. Change the pipeline and regenerate instead.

## How it works

- `screenshots/seed.ts` signs up five demo users through the real API, with verification codes read from MailHog. It then builds a small world: connections and follows, DMs with a thread and reactions, a group, a space with an announcements channel and a design channel, profile posts, a saved post, a pending connection request, and three public channels for Discover.
- `screenshots/capture.spec.ts` opens each screen as the demo user "Ava Chen" and writes the PNGs:
  - desktop at 1440×900, with dark variants of two screens
  - mobile at 390×844 and 2× scale
- It also copies two hero shots and a Swagger UI capture into `../VoiceChat/docs/images/` for the backend README.
- `playwright.screenshots.config.ts` is separate from the e2e config. It starts Vite on port 3100 pointed at the screenshot API.

Each run creates new users with a random suffix, so it never collides with an earlier run.

## Regenerating

The pipeline needs a backend on port **8002** backed by a **fresh database**, so that Discover and the directory show only seeded data. It also needs an email worker for the test queue. From `../VoiceChat`:

```bash
# infrastructure, MailHog and the regular worker
docker compose --profile test up -d mongo redis rabbitmq mailhog minio worker

# the test API's emails go to email.send.test; deliver them to MailHog
docker compose run -d --rm --no-deps --name voicechat_email_worker_test \
  -e EMAIL_QUEUE_NAME=email.send.test worker python -m app.workers.email_worker

# a throwaway API on :8002 using its own database
docker compose --profile test run -d --rm --no-deps --name voicechat_api_screenshots \
  -p 8002:8000 -e MONGO_DB=vogi_screenshots api_test \
  uvicorn app.main:asgi_app --host 0.0.0.0 --port 8000
```

Then, from this repository:

```bash
npm run docs:screenshots
```

To regenerate from a clean slate later, drop the screenshot database first. This deletes only `vogi_screenshots`:

```bash
docker exec voicechat_mongo mongosh vogi_screenshots --quiet --eval 'db.dropDatabase()'
```

Set `SCREENSHOT_API_URL` or `SCREENSHOT_MAILHOG_URL` to point the pipeline somewhere else.
